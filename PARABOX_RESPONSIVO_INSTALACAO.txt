</html>

[FERRAMENTAS] USAR FUNÇÕES JAVASCRIPT:

Detectar Tipo de Dispositivo:
──────────────────────────────
if (ResponsiveHelpers.isMobile()) {
    console.log("É um telemóvel!");
}

if (ResponsiveHelpers.isTablet()) {
    console.log("É um tablet!");
}

if (ResponsiveHelpers.isDesktop()) {
    console.log("É um desktop!");
}

Obter Breakpoint Atual:
───────────────────────
const bp = ResponsiveHelpers.getCurrentBreakpoint();
// Retorna: 'xs', 'sm', 'md', 'lg', 'xl', 'xxl'

Detectar Orientação:
────────────────────
if (ResponsiveHelpers.isPortrait()) {
    console.log("Retrato");
}

if (ResponsiveHelpers.isLandscape()) {
    console.log("Paisagem");
}

🆘 TROUBLESHOOTING RÁPIDO:

Problema: "Menu não funciona em móvel"
├─ Verificar se responsive.js está incluído
├─ Abrir console (F12) e procurar erros
└─ Recarregar página (Ctrl+Shift+R)

Problema: "Texto muito pequeno/grande"
├─ Ajustar valores clamp() em responsive-helpers.css
├─ Testar com zoom do browser (Ctrl +/-)
└─ Verificar resolução mínima

Problema: "Tabelas não ficam bem em móvel"
├─ Adicionar classe "table-wrapper" ao redor
├─ Permitir scroll horizontal
└─ Testar em landscape
